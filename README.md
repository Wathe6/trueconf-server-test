## Запуск в Docker

Использован образ [`trueconf/trueconf-server:stable`](https://hub.docker.com/r/trueconf/trueconf-server) на Docker Hub. [Команда создания контейнера для PowerShell](<docker_run.md>), [документация Docker](https://docs.docker.com/get-started/). Повторный запуск созданного контейнера: `docker start vcs_server_local`.

Панель управления: [http://127.0.0.1:8080/admin/](http://127.0.0.1:8080/admin/). Тестовый администратор: `tc_admin`, пароль: `password`.

## Дополнительные замечания

Замечания вынесены отдельно от результатов тест-кейсов раздела «Веб».

| № | Замечание | Наблюдение | Ожидаемое поведение |
| --- | --- | --- | --- |
| 1 | Отсутствует настройка документов для разных языков | Нельзя отдельно задать содержимое документов для разных локалей. До редактирования cookie-документ на гостевой странице был на английском, а в панели – на русском. После сохранения изменений на гостевой странице также появился русский текст. | Возможность задавать версии документов для разных языков. Пожелание к функциональности; требуется уточнение требований. |
| 2 | Виджет чата сбивает фокус с поля | При появлении виджета чата фокус уходит из поля, в котором выполнялся ввод. | Появление виджета не должно менять фокус без действия пользователя. |
| 3 | Ошибки в документации по установке сервера на докер контейнер | В [документации](https://trueconf.ru/blog/baza-znaniy/kak-zapustit-trueconf-server-v-docker-kontejnere#adding-trueconf-admins) дублируется пункт 5 и в следующем пункте повторяются абзацы. | Последовательная нумерация пунктов и отсутствие повторяющихся абзацев. |
